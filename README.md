A lightweight Python script that renders detailed ASCII flower bouquet art directly in the terminal.

## Requirements

* **Python 3.x** installed on your system (no external libraries required).

## How to Run

1. Clone or download this repository to your computer.
2. Open your terminal, Command Prompt, or PowerShell inside the project folder.
3. Run the script:
   ```bash
   python bouq.py
